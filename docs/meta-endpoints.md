# Meta endpoints, permissions and limits — verification log

**Golden rule: verify, don't remember.** Meta changes Graph API versions, endpoints,
metrics, limits and permissions frequently, and its own documentation pages
sometimes disagree with each other or lag behind actual behavior. Nothing in
`src/meta/` should hardcode a number or permission name from memory or from a
blog post — check the cited developers.facebook.com page for the app's
configured `META_GRAPH_VERSION`, and re-verify before every release.

**Session limitation (read before trusting anything below as "primary-source
verified"):** in this research session, direct `WebFetch` requests to
`developers.facebook.com` and to `web.archive.org` were both blocked by the
sandbox's network egress proxy (`EGRESS_BLOCKED`). All findings below come
from `WebSearch`, which returns short AI-synthesized snippets built from
search-index copies of pages (including, for some items, third-party blogs
that resurface official numbers). Where a finding could be cross-checked
against an official `developers.facebook.com` page **title/URL** appearing in
the result set, confidence is noted as such. Where the only source was a
third-party blog, it is marked **UNVERIFIABLE** even if the number is
probably right, per the "never rely on blog posts" rule. Before shipping,
re-run these checks with a working fetch of the actual pages.

## Summary of things that changed scope or need a decision

1. **Login model is more flexible than the skill assumed.** Private replies and
   Instagram DM messaging no longer require Facebook Login for Business — they
   are documented natively under Instagram API with Instagram Login
   (`instagram_business_manage_messages`). Only **Business Discovery**,
   **Hashtag Search**, and **native Facebook Page publishing/insights**
   genuinely require Facebook Login for Business (a Page-linked account).
   → Decide whether `meta-content-mcp` needs Business Discovery/Hashtag
   Search (research features) badly enough to require the heavier Facebook
   Login for Business flow, or whether v1 can ship Instagram-Login-only for
   IG accounts and add Facebook Login only for Page-owning users.
2. **Content publishing daily quota must never be hardcoded** — official
   sources disagree (25 / 50 / 100 seen across cached/older/newer pages).
   Always read it live from `content_publishing_limit`, exactly as the skill
   already instructs.
3. **Business Use Case rate-limit codes**: the skill's `80001–80014` range is
   not confirmed as exhaustive or accurate (one source shows `80000` for Ads
   Insights, outside that range). Before finalizing the error-mapping table,
   fetch the live rate-limiting pages directly (this session's network egress
   to developers.facebook.com and web.archive.org was blocked) rather than
   trusting the range as given.
4. **Caption/hashtag/mention limits (2,200 / 30 / 20)** could only be sourced
   from third-party blogs this session — treat as unverified placeholders,
   not as validated limits, until re-checked against the official `/media`
   reference page.
5. **Graph API version**: default `META_GRAPH_VERSION` should be `v26.0`
   (latest stable, released 2026-07-29). Avoid `v20.0` — it expires in 7 days
   (2026-09-24).
